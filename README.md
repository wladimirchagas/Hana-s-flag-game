# Guess the Flag 

MVP flag quiz: see a country flag, search and select a country, confirm your guess, and track your score (+1 correct, −1 wrong).

## Setup

```bash
npm install
npm run dev
```

Open the URL shown in the terminal (usually `http://localhost:5173`).

## Build

```bash
npm run build
npm run preview
```

## Data

Country names and flag images come from [REST Countries](https://restcountries.com) (no API key). You need network access in the browser for the game to load.
